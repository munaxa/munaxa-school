# Munaxa AI Generation Rules

Canonical implementation guidance lives in client/src/design-system/guidelines/ai-generation-rules.mdx.

AI-generated interfaces must select a product pattern, apply capability and scope, implement workflows as explicit state machines, emit notifications from domain events, and compose domain components through public APIs. Cover loading, empty, error, denied, read-only, approval-pending, dark, and RTL behavior.

Do not invent permissions, expose sensitive fields, copy component markup, transition server workflow only in the client, use raw colors, use emoji icons, use physical left/right positioning, or introduce neon, glow, glassmorphism, or decorative dashboards.
