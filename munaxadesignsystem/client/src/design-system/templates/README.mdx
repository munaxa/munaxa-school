# Dashboard templates

## Overview
Templates provide production-ready page hierarchy for Principal, Finance, Attendance, Teacher, and Reports dashboards.

## Usage
Supply role-specific data and actions through the shared `DashboardTemplate`; keep metric count at four or fewer and retain the overview/attention hierarchy.

## Examples
Each exported template includes realistic school-operation metrics, a primary analysis region, and actionable exceptions.

## Best Practices
Replace placeholders with accessible charts or tables, include scope and freshness, and keep the primary action role-specific.

## Accessibility Notes
Metric groups are labelled sections, headings remain ordered, and icon-only controls have accessible names.

## RTL Notes
The grid and flex layouts use logical document flow. Chart implementations must independently support RTL labels and tooltips.
